OmaShelf

A file shelf in the Omarchy bar. Drop files, photos, videos and text on it, then drag them out into any app.

curl -fsSL https://omashelf.buddytools.org/install.sh | bash

Needs Omarchy's Quickshell desktop. Run it again to update.

Use

Drop
Drop files on the tray icon. Hold them there and the shelf opens.
Ctrl V
Paste copied files, a screenshot or text. Middle-click the icon does the same. Images and text become new files.
Drag out
Drag a file into a browser, chat or editor. Select several to drag them together.
Ctrl C
Copy the selection. One image goes to the clipboard as an image, so it pastes into chats.
Enter
Open the file. The folder icon shows it in your file manager.
Delete
Remove from the shelf. Your files stay where they are.
Ctrl O
Add files with the file picker.
/
Filter by name once the shelf holds more than eight files.

Details

  1. The shelf keeps links to your files. Pasted images and text are saved in ~/.local/share/omashelf and deleted when you remove them.
  2. Every monitor's bar shows the same shelf.
  3. It uses python3, wl-clipboard and ffmpegthumbnailer, which Omarchy already ships. The installer lists anything missing.
  4. The shell runs plugins as your user, without a sandbox. Read the source on GitHub before you install.
  5. Without the script: omarchy plugin add https://github.com/OxFrancesco/OmaShelf --enable
